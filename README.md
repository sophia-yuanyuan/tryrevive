# TryRevive

> 面向在校大学生：找回停滞项目的上次现场，完成今天最关键的一步，下次从真实进度继续。

[体验地址（外发前需复核）](https://sophia-yuanyuan.github.io/tryrevive/) · [项目仓库](https://github.com/sophia-yuanyuan/tryrevive)

## 为什么做

很多大学项目并不是因为学生没有目标而停滞。原因可能是上下文断裂、下一步太大，也可能是项目已经不重要，或真正缺少技能、反馈、伙伴和必要依赖。传统待办工具通常只记录任务，很少帮助学生恢复“上次做到哪里、这个项目还值不值得继续、现在最有意义的一步是什么”。

TryRevive 的首发产品方向是：

- **核心：大学生停滞项目复活。** 服务课程、竞赛、作品集、科研和毕业设计，先找回现场，再确认一个有完成标准的下一小步。
- **持续：从真实进度继续。** 完成后留下成果和下次入口，减少数天后重新理解项目的成本。
- **辅助：注意力守护。** 现有关键词直达、限时浏览、冥想与心语属于历史辅助能力，不应阻挡首次项目复活流程。

## 核心闭环

1. 选择一个已经停滞的真实大学项目。
2. 找回最近成果、截止节点、当前阻力和可用时间。
3. 判断继续、缩小、求助、暂停还是放弃。
4. 若继续，确认一个有完成标准的下一小步。
5. 执行后用文字、链接或文件名留下本次成果。
6. 安排回流，下次从成果继续。

当前公开 MVP 已具备恢复、动作、进度和回流的基础实现；“项目判断”和条件式“帮我问清楚”属于新的学生 MVP 规格，尚不能描述为线上已实现。

## 当前已经实现

- 游客体验、注册/登录与浏览器本地存档
- 对话式与表单式项目复活
- Revival Brief 与规则驱动的 5–10 分钟下一步
- 行动计时、完成证据、继续行动与 45 分钟短冲刺
- 项目列表、暂停/恢复、周复盘与 JSON 数据导出
- 关键词直达、常用应用入口、限时浏览与回流提示
- 冥想空间、桌宠和可降级的 AI 心语
- Chrome Extension MV3 原型
- 公开公众号文章的本地知识库与来源引用实验

## AI 设计原则

TryRevive 不让 AI 生成更长的计划，而是把智能能力约束在“恢复上下文、缩小行动、验证完成”。

当前 MVP 的项目复活主流程由结构化对话和本地规则引擎保证，即使 AI 服务不可用仍可运行。AI 辅助层用于温和心语和基于用户提供资料的知识问答；服务不可用时会降级为本地模板或本地检索，不阻断核心闭环。

## 本地运行

项目是静态 Web 应用，无需构建：

```powershell
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。

## 仓库结构

- 根目录：当前静态 Web 应用与 GitHub Pages 必需文件。
- `icons/`、`lanshi/`：主应用直接引用的运行时资源。
- `chrome-extension/`：Chrome Extension MV3 原型。
- `worker/`：Cloudflare Worker 后端。
- `tests/`：核心模块与浏览器端测试。
- `docs/`：产品、部署和功能文档。
- `design/`：设计系统、素材、参考资料与本地原型。
- `marketing/`：产品介绍、目标受众、用户故事与对外话术草案。
- `tools/`：不参与线上运行的一次性辅助脚本。

详细说明见 [`docs/README.md`](docs/README.md)、[`design/README.md`](design/README.md)、[`marketing/README.md`](marketing/README.md) 和 [`tools/README.md`](tools/README.md)。

## 数据与边界

- 项目与偏好数据默认保存在当前浏览器，可由用户主动导出。
- 核心复活流程不依赖远程 AI，也不会自动修改用户的外部文件。
- 公众号实验只处理用户主动提供的公开链接或正文，不绕过登录、验证码或平台访问限制。
- 当前仍是公开 MVP，不应当被当作跨设备备份或正式云存储服务。

## 当前状态与下一步

仓库保留公开体验地址，但本轮没有重新确认线上页面与本地候选版是否一致。近期优先级：

1. 用 5–10 个真实停滞学生项目验证三分钟下一步、7 天实质成果和 30 天继续。
2. 把首次流程收紧到学生场景，减少叙事、登录、人格和注意力功能对核心价值的阻挡。
3. 在明确同意后补充去标识、假名化事件，记录建议修改/拒绝原因和无需重新解释的回流。
4. 验证条件式“帮我问清楚”，不让它成为强制流程。
5. 只有在用户价值成立后，再决定云同步、连接器、Agent、商业化和后端扩展。

产品主文档见 [`docs/product/PRD_STUDENT_MVP.md`](docs/product/PRD_STUDENT_MVP.md)，90 天目标见 [`docs/growth/90_DAY_1000_STUDENTS.md`](docs/growth/90_DAY_1000_STUDENTS.md)。
