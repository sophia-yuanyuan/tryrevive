# Cohere · Design system migration spec

> Source: https://cohere.com  ·  Curated by OpenDesign  ·  ko

> 이 사이트는 타이포그래피와 여백을 활용하여 파워와 신뢰를 전달하는, 절제되면서도 임팩트 있는 SaaS 디자인의 훌륭한 예시입니다.

## 1. 디자인 DNA

Cohere의 디자인 시스템은 잘 보호된 금고처럼 작동합니다: 그 강점은 화려한 장식에 있지 않고 규율 잡힌 구조에 있습니다. 아이덴티티는 검은색과 흰색의 엄격하고 고대비를 기반으로 단조되어, 즉각적인 권위와 엔터프라이즈급 보안감을 확립합니다. 이 목적의 명확성은 모든 구성 요소와 인터랙션이 구축되는 초석이며, 일시적인 유행이 아닌 강력한 AI 인프라에의 집중을 알립니다.

**One-liner:** 개발자 도구와 데이터 소유권에 초점을 맞춘 깔끔하고 프리미엄한 AI 플랫폼입니다.
**Keywords:** AI · 인프라 · 소유권 · 데이터 · 개발자
**Analogy:** 기업용 AI를 위한 깔끔하고 프리미엄 기술 플랫폼입니다.

## 2. 컬러

팔레트는 절제에 대한 연구로, 고대비 흑백 기반 위에 구축됩니다. 강조 색은 외과적 정밀도로 사용되며, readiness 칩과 같은 중요한 상태 표시기에만 엄격히 적용되어 시야가 지저분하지 않도록 하고 주요 콘텐츠가 주의를 끌도록 보장합니다.

| Token | 값 | 용도 |
|---|---|---|
| `--bg` | `#FFFFFF` | main background |
| `--bg-soft` | `#F9FAFB` | card background |
| `--ink` | `#000000` | body text |
| `--ink-soft` | `#4B5563` | secondary text |
| `--muted` | `#9CA3AF` | placeholder |
| `--accent` | `#1E1E1E` | single accent |
| `--line` | `rgba(229, 231, 235, 1.0)` | divider |

**컬러 원칙:** 서브티브한 그레이를 통한 계층 구성을 위한 고대비 모노크롬 팔레트이며, 일러스트레이션에서 브랜드 고유 색상으로 포인트를 줍니다.

원칙은 절대적입니다: 대비와 명확성을 최우선으로 하며, 색상은 특정 기능적 의미를 가질 때에만 사용합니다.

## 3. 타이포그래피

타이포그래피는 깨끗한 기하학적 sans-serif로 설정되어, 현대적이면서도 권위 있는 톤을 확립합니다. 스케일은 의도적으로 제한되어, 주로 웅장한 히로 헤드라인과 단락 및 내비게이션을 위한 정확하고 가독성 높은 텍스트를 구별하며, 장식적 장식보다 정보의 위계를 강화합니다.

- **Display:** sans-serif
- **Body:** sans-serif
- **Mono:** monospace

| Token | Size | Line-height | Weight | Letter-spacing | 용도 |
|---|---|---|---|---|---|
| display | 56px | 1.1 | 400 | -1px | 기본 헤드라인 (Own your AI) |
| headline | 32px | 1.2 | 400 | 0px | 서브 헤드라인 (Your data...) |
| body | 16px | 1.5 | 400 | 0px | 일반 본문 텍스트 |
| caption | 14px | 1.4 | 400 | 0px | 보조 정보 |

**타이포 규칙:**
- 디스플레이 폰트는 매우 읽기 좋은 sans-serif입니다.
- 본문 텍스트는 표준 시스템 폰트 스택 대체를 사용합니다.
- 코드 요소에는 모노스페이스를 사용합니다.

## 4. 여백

넓은 수직 간격이 시스템의 리듬을 정의하며, 각 요소가 레이아웃 내에서 숨 쉴 수 있도록 합니다.

- **Base unit:** 4px
- **Scale:** 4 / 8 / 16 / 24 / 32 / 48 / 64 / 96 px
- **Rhythm:** 여유로운 여백과 표준 8pt 기반 spacing 스케일을 사용합니다.

## 5. 표면 (라운드 / 그림자 / 경계선)

깊이는 차원 효과가 아닌 깨끗한 분리를 통해 전달됩니다. 표면은 미세한 1px 테두리에 의존하거나, 더 자주는 여백과 레이아웃 배치의 지능적 사용으로 경계를 정의합니다.

- **Radius:** sm 4px · md 8px · lg 12px · pill 999px
- **Shadows:**
  - 0px 4px 6px -1px rgba(0, 0, 0, 0.1)
- **Borders:** 1px solid #E5E7EB

## 6. 레이아웃

레이아웃 골격은 중심을 잡은 단일 열 히로로 시작하여 핵심 메시지를 권위 있게 확립합니다. 그런 다음 제품과 사용 사례를 명확성과 시각적 풍부함으로 전시하도록 설계된 다중 열 비주얼 그리드로 전환됩니다.

- **Container max:** 1200px
- **Paragraph max:** 680px
- **Grid:** 12 columns, gutter 24px
- **Breakpoints:** 768 / 1024 px

**Skeleton:** 중앙 정렬 컨테이너가 있는 표준 12컬럼 그리드입니다.

## 7. 모션과 인터랙션

모션 철학은 전문적인 목적과 최소한의 개입입니다. 기간은 마이크로(220ms)에서 중간(800ms)으로 미세 조정되어 명확하고 부드러운 상태 변화를 만들며, 주의를 산만하게 하지 않는 일관된 ease 커브에 의해 제어됩니다.

- **Durations:** micro 220ms · small 400ms · medium 800ms
- **Easing:** `cubic-bezier(0.4, 0, 0.2, 1)`
- **Patterns:**
  - hover 상태를 위한 부드러운 전환입니다.
  - 콘텐츠 섹션을 위한 서브티브한 페이드인입니다.

- **Hover:** 미세한 색상 변화 또는 약간의 높이 변화입니다.
- **Click:** 축소 또는 색상 전환입니다.
- **Transition:** 모든 속성이 부드럽게 전환됩니다 (all 0.2s ease).
- **Keyboard:** 접근성을 위한 표준 focus 윤곽선입니다.

## 8. 보이스와 금지 목록

에디토리얼 보이스는 권위 있고, 자신감 넘치며, 직접적입니다. 헤드라인은 짧고 선언적인 문구이며, 행동 유도 문구는 명확하고 행동 지향적입니다. 이는 디자인 자체의 직선적인 정확성을 반영합니다.

- **Tone:** 전문적이고 자신감 있으며 약간 기술적인 어조입니다.
- **Headline style:** 직설적이고 강렬하며 이점 중심적입니다.
- **CTA style:** 행동을 유도하는 표현입니다 (예: 데모 요청, 제품 탐색).
- **Avoid:** 과도한 전문 용어 / 지나치게 캐주얼한 어조 / 모호한 문구

### 금지 목록
- ❌ 드롭 섀도우를 사용하지 않습니다 — 스크린샷은 대신 서브티브한 테두리가 있는 플랫 디자인을 보여줍니다
- ❌ 복잡한 그라디언트를 사용하지 않습니다 — 스크린샷은 대신 깨끗한 흰색 배경을 보여줍니다
- ❌ 장식용 아이콘을 사용하지 않습니다 — 스크린샷은 대신 미니멀한 아이콘 사용을 보여줍니다
- ❌ 본문 텍스트에 올캡스를 사용하지 않습니다 — 스크린샷은 대신 표준 문장형 대소문자를 보여줍니다
- ❌ 배경으로 밝은 기본 색상을 사용하지 않습니다 — 스크린샷은 대신 흰색 위의 어두운 텍스트를 보여줍니다
- ❌ 헤드라인에 세리프 폰트를 사용하지 않습니다 — 스크린샷은 대신 깔끔한 sans-serif를 보여줍니다

시스템은 장난스러운 언어, 복잡한 그라디언트, 장식 요소를 의도적으로 생략하여 진지하고 엔터프라이즈 중심의 자세를 유지합니다.

## System Prompt (AI 도구에 붙여넣기)

```
이것은 개발자와 기업을 대상으로 하는 깔끔하고 프리미엄한 AI 플랫폼입니다. 고대비 모노크롬 팔레트(#000000 대 #FFFFFF), 서브티브한 그레이(#4B5563, #9CA3AF), 그리고 얇은 테두리(#E5E7EB)를 특징으로 합니다. 타이포그래피는 humanist-sans와 grotesque-sans 카테고리에 의존하며, 56px 디스플레이에서 14px 캡션까지 명확한 계층 구조를 가집니다. 레이아웃은 여유로운 12컬럼 그리드와 표준 8pt 간격을 사용합니다. 중요한 주의사항은 다음과 같습니다: 드롭 섀도우 없음, 복잡한 그라디언트 없음, 장식용 아이콘 없음, 본문 텍스트 올캡스 없음, 밝은 배경 없음, 세리프 헤드라인 없음. 어조는 전문적이고 기술적이며, 직설적인 CTA를 사용합니다.
```
