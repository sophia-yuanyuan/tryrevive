# Cohere · Design system migration spec

> Source: https://cohere.com  ·  Curated by OpenDesign  ·  zh-CN

> 这是一个将克制与高影响力完美结合的SaaS设计典范，依靠字体与留白来传递力量与可信度。

## 1. 设计气质 DNA

Cohere 的设计系统如同一座戒备森严的金库：其力量并非源于华丽的装饰，而是来自严谨的结构。这套设计系统建立在黑白分明的高对比度基础上，立刻营造出权威感与企业级的安全感。这种明确的目标是构建每个组件与交互的基石，彰显其对强大 AI 基础设施的专注，而非追逐短暂潮流。

**One-liner:** 一个专注开发者工具和数据所有权的、干净高端的AI平台。
**Keywords:** AI · 基础设施 · 所有权 · 数据 · 开发者
**Analogy:** 一个干净、高端的企业级AI技术平台。

## 2. 色彩

色彩体系是克制的典范，以高对比度的黑白为基础。强调色仅以极其精确的方式使用，严格保留给诸如就绪状态指示器等关键状态标识，确保视觉场域保持整洁，让核心内容占据注意力中心。

| Token | 值 | 用法 |
|---|---|---|
| `--primary` | `#FF8A65` | TryRevive 主按钮、选中状态、链接与焦点 |
| `--bg` | `#FFFFFF` | main background |
| `--bg-soft` | `#F9FAFB` | card background |
| `--ink` | `#000000` | body text |
| `--ink-soft` | `#4B5563` | secondary text |
| `--muted` | `#9CA3AF` | placeholder |
| `--accent` | `#1E1E1E` | single accent |
| `--line` | `rgba(229, 231, 235, 1.0)` | divider |

**用色原则:** 高对比度中性色负责信息层级；TryRevive Warm Coral `#FF8A65` 是唯一主色，只用于主按钮、选中、链接和焦点，每屏最多一个主按钮。

原则是绝对的：对比度与清晰度优先，仅在传达特定功能含义时使用色彩。

## 3. 字体

字体采用清晰的几何无衬线体，确立现代而权威的基调。字体尺寸比例经过精心规划，主要区分具有主导性的大标题与用于段落及导航的精确易读正文，强化信息层级高于装饰性细节的理念。

- **Display:** sans-serif
- **Body:** sans-serif
- **Mono:** monospace

| Token | Size | Line-height | Weight | Letter-spacing | 用法 |
|---|---|---|---|---|---|
| display | 56px | 1.1 | 400 | -1px | 主标题（拥有你的AI） |
| headline | 32px | 1.2 | 400 | 0px | 副标题（你的数据...） |
| body | 16px | 1.5 | 400 | 0px | 标准正文 |
| caption | 14px | 1.4 | 400 | 0px | 次要信息 |

**字体规则:**
- 标题字体使用高度易读的无衬线体。
- 正文使用标准系统字体栈回退方案。
- 代码元素使用等宽字体。

## 4. 间距

充裕的垂直间距定义了系统的节奏，让每个元素在布局中都能有呼吸的空间。

- **Base unit:** 4px
- **Scale:** 4 / 8 / 16 / 24 / 32 / 48 / 64 / 96 px
- **Rhythm:** 充裕的留白和标准的基于8pt的间距体系。

## 5. 表面 (圆角 / 阴影 / 边线)

层次感通过清晰的分隔而非立体效果来传达。界面依靠细微的 1px 边框，或更常见地，通过智能运用留白和布局位置来界定边界。

- **Radius:** sm 4px · md 8px · lg 12px · pill 999px
- **Shadows:**
  - 0px 4px 6px -1px rgba(0, 0, 0, 0.1)
- **Borders:** 1px solid #E5E7EB

## 6. 布局

布局骨架始于居中的单列大标题区，以权威姿态确立核心信息。随后过渡到多列视觉网格，旨在清晰而丰富地展示产品与用例。

- **Container max:** 1200px
- **Paragraph max:** 680px
- **Grid:** 12 columns, gutter 24px
- **Breakpoints:** 768 / 1024 px

**Skeleton:** 标准的12列栅格布局，容器居中。

## 7. 动效与交互

动效理念是专业导向与最小干预。持续时间从微观（220ms）到中等（800ms）精心校准，以实现清晰、流畅的状态变化，并由统一的 ease 缓动曲线控制，避免分散注意力。

- **Durations:** micro 220ms · small 400ms · medium 800ms
- **Easing:** `cubic-bezier(0.4, 0, 0.2, 1)`
- **Patterns:**
  - hover状态采用平滑的过渡动画。
  - 内容区域采用微妙的淡入效果。

- **Hover:** 颜色发生微妙变化或略微提升高度。
- **Click:** 轻微缩放或颜色偏移。
- **Transition:** 所有属性平滑过渡（all 0.2s ease）。
- **Keyboard:** 采用标准的focus轮廓以满足无障碍访问要求。

## 8. 文案语气与禁用清单

编辑风格权威、自信且直接。标题是简短、陈述性的句子，行动号召清晰且目标明确，反映了设计本身直截了当的精确性。

- **Tone:** 专业、自信，并略带技术感。
- **Headline style:** 直接、有力，并聚焦于用户收益。
- **CTA style:** 以行动为导向（例如：申请演示、探索产品）。
- **Avoid:** 过度使用行话 / 过于随意的语气 / 表述模糊

### 禁用清单
- ❌ 避免使用投影——设计稿展示的是搭配微妙边框的扁平化设计
- ❌ 避免使用复杂渐变——设计稿展示的是干净的白色背景
- ❌ 避免使用装饰性图标——设计稿展示的是极简的图标使用
- ❌ 避免正文字体全大写——设计稿展示的是标准的句子大小写
- ❌ 避免使用明亮的主色作为背景——设计稿展示的是白色背景上的深色文字
- ❌ 避免标题使用衬线字体——设计稿展示的是干净的无衬线字体

该系统刻意省略了俏皮语言、复杂渐变和装饰元素，以保持其严肃、专注企业级应用的定位。
