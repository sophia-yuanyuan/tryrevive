# 黑胶星球与项目音乐验收

状态：`PARTIAL CURRENT`；单张仪式与收藏总览均已进入真 3D 工程阶段，真人与听感验收仍未完成

适用版本：`codex/frontend-platform` 当前奖励分段提交，应用版本 `0.8.0`

这份清单给不看代码的产品负责人使用。验收的不是“代码写了多少”，而是一个完成项目或放弃项目能否真实走到收藏、刷新后仍存在，并且音乐能否真的导出。

## 先知道当前边界

### CURRENT

- 完成项目时选择一种真实心情，结果保存在本机。
- 完成项目进入黑胶星球；放弃项目进入黑洞历史，记录不会删除。
- 已完成且选择心情的项目使用本地 WebGL 真 3D 仪式，可依次打开封套、取出唱片、放到唱盘、落针播放并收藏；显卡绘制失败时自动切到可操作的简化画面。
- 收藏总览使用本机 WebGL 真 3D：透视相机、程序化星场、黑洞核心、多层吸积盘和三维唱片轨道；场景不使用电影素材或网络纹理。
- 星球可用鼠标拖动、触摸滑动、方向键转动；Canvas 外保留全部项目按钮，所有项目也可用 `Tab` 和 `Enter` 打开。
- 完成、待选择心情和已放下项目使用不同轨道与材质；最多 100 个项目都进入 3D 实例布局，不再只显示前 12/8 个。
- WebGL 创建失败或 context 丢失时，当前选择不丢失，并自动回到完整的 DOM 项目列表。
- 曲目根据项目身份、完成心情、每一步实际用时和成果数量确定，同一份项目数据会得到同一首曲目。
- 音乐在本机生成 48–96 秒、单声道、22.05 kHz、16-bit PCM WAV；播放和导出使用同一份 WAV。
- 网页版下载 WAV；Windows 桌面版弹出“另存为”。
- 支持减少动态效果；摄像头默认关闭，只有用户主动同意后才启动随包 MediaPipe 模型和本地预览。
- 完成唱片的摄像头预览位于 3D 舞台左上角；21 点手部关键点驱动开掌、捏取、跟随、松开放盘与唱针命中，具有迟滞、稳定保持、短暂丢手冻结和长时间丢手取消。鼠标、触摸和键盘始终可用。

### PARTIAL CURRENT

- 3D 总览已有工程实现和自动测试，但还没有完成“12 张完成唱片 + 8 份放下记录”的真人点击、触控、空间层次与审美验收，因此不能声称已经达到最终电影感。
- 21 点手势已有工程实现和纯函数测试，但还没有完成不同光线、肤色、手型和摄像头下每个动作 10 次、至少成功 8 次的真人验收，因此不能声称“手势已经精准”。
- 音乐是本地规则合成的完整 WAV 文件，不是生成式音乐模型、多轨工程或商业发行母带。
- 如果旧项目没有记录真实开始时间，会使用当时计划分钟数作为兜底，并在代码测试中区分这两种来源。

### 仍未实现

- 黑胶星球的最终美术调色、真实触控命中率和中低端 GPU 性能验收。
- 21 点捏取、跟随、放盘和落针的真人成功率验收与按实测结果调参。
- 经过产品负责人试听通过的原创分轨编曲；参考歌曲不会作为采样或应用资产进入仓库。
- 真实账户、充值支付和云端算力扣费。
- 面向真实用户的云端语音识别、附件理解和 LLM 分析。

## 验收路径 A：完成项目进入黑胶星球

1. 打开 TryRevive，输入一个你愿意测试的项目名称。
2. 依次填写“上次最后完成了什么”和“具体卡在哪里”。
3. 选择继续或缩小，确认下一小步，进入专注界面。
4. 点击“我留下了一个结果”，写下一条实际成果并安排下次继续。
5. 在“下次不用从头回忆”页点击“这个项目已经完成”。
6. 选择最接近当时感受的一种心情，例如“踏实的骄傲”。

算通过：

- 页面进入“这个项目已经完成”；
- 封套可以点击打开，唱片从封套侧面取出；
- 页头出现“黑胶星球”入口；
- 进入星球后，完成唱片列表中出现刚才的项目；
- 页面明确显示所选心情、记录分钟数和曲目时长。

## 验收路径 B：播放、导出与刷新

1. 在黑胶星球选中刚才的完成项目。
2. 点击“播放项目唱片”，确认设备真正发出声音；再次点击可暂停。
3. 点击“导出同一首 WAV”。
4. 网页版确认下载文件名是“项目名.wav”；桌面版选择一个位置保存。
5. 用系统播放器打开 WAV。
6. 返回 TryRevive 并刷新，或关闭桌面应用后重新打开，再进入黑胶星球。

算通过：

- 导出的 WAV 可以被系统播放器打开；
- 刷新或重启后项目、完成心情和唱片仍存在；
- 同一项目重新播放/导出的曲目参数不变；
- 取消“另存为”不会报错，也不会产生空文件。

## 验收路径 C：放弃项目进入黑洞历史

1. 新建另一个用于测试的项目并找回现场。
2. 在“现在最诚实的选择是什么？”选择“放弃”。
3. 进入黑胶星球。
4. 点击黑洞、弯折唱片，或在“黑洞历史”列表里打开该项目。

算通过：

- 项目不再出现在进行中列表；
- 它出现在“黑洞历史”，而不是被删除；
- 页面使用“已经放下”“记录仍保留”等中性文案；
- 不出现人格评价、羞辱或失败惩罚。

## 验收路径 D：不用鼠标也能完成

1. 按 `Tab` 把焦点移到黑胶星球场景。
2. 使用四个方向键转动真 3D 场景。
3. 继续按 `Tab` 进入下方项目列表，选中一张唱片后按 `Enter` 打开。
4. 在 Windows“设置 → 辅助功能 → 视觉效果”关闭动画效果，或在浏览器模拟 `prefers-reduced-motion: reduce` 后重复以上步骤。

算通过：

- 主要操作都有可见焦点；
- 不用鼠标也能打开项目、播放和导出；
- 减少动态效果后，自动过渡被压缩，但内容和按钮没有消失。

## 自动验证证据

- 以当前提交实际执行的 `npm run check`、Web E2E 和 Electron E2E 输出为准；旧测试数量不再作为事实证据写死。
- 自动测试覆盖 3D renderer/fallback、DOM 选择同步、context lost 后选择保留、完成/放下列表与单张黑胶仪式。

自动测试不能代替三项人工确认：设备是否实际发声、真人手势是否舒服可靠，以及 Windows“另存为”对话框中选择真实路径后的文件能否被你常用的播放器打开。
