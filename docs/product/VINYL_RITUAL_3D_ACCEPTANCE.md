# TryRevive 真 3D 黑胶仪式验收

状态：`NEW CONCEPT`，按独立可回退提交逐段实现

品牌：`TryRevive`

## 这次要替换什么

当前收藏页的星球由 CSS 透视模拟，完成奖励只需点击封套和播放按钮，摄像头手势只能旋转、选择和打开；本地 WAV 由单声道规则合成器生成。这些能力可以证明数据链路，但没有形成用户想要的空间感、动作仪式和音乐成就感。

目标体验按同一条状态机完成：

```text
封套闭合
  -> 打开封套
  -> 捏住并取出唱片
  -> 把唱片放到唱盘
  -> 把唱针放到唱片上
  -> 用户主动开始播放
  -> 播放结束或主动停止
  -> 收藏回黑胶星球
```

动画、手势和声音都不能替用户宣布项目完成。只有用户已经明确确认完成且选择完成心情的项目，才能进入这段仪式。

## 分段范围

### R1：真 3D 手动仪式

- 使用随应用打包的 Three.js 和本地 WebGL 渲染封套、唱片、唱盘、唱针、灯光与空间背景。
- 鼠标拖拽、触摸拖拽和键盘按钮调用同一个纯状态机，不能跳过阶段。
- WebGL 创建失败或 context lost 时，切换到可操作的 DOM 降级界面，不出现黑屏。
- `prefers-reduced-motion` 开启时取消镜头飞行、粒子和缓动，但保留所有状态与操作。

### R2：真人手势与摄像头画中画

- 张开手掌打开封套。
- 拇指与食指捏合抓住唱片，保持捏合时唱片跟随手部位置。
- 在唱盘命中区松开才算放盘；其他位置松开会安全回到可重试状态。
- 唱针使用独立命中区和确认动作，避免抓盘时误播放。
- 使用 21 点手部关键点、尺度归一化、迟滞、稳定时间和松手重新武装；不再把低频 canned gesture 当成精确抓取。
- 摄像头默认关闭。预览固定在舞台左上角且可收起，不遮挡星球、唱盘或唱针；画面不保存、不上传。
- 拒绝权限、模型失败或关闭摄像头后，完整手动链路仍可用。

### R3：真 3D 黑胶星球

- 完成唱片存在于真实三维坐标、相机、光照和轨道中，可用 raycast 选中。
- 黑洞使用原创的吸积盘、光晕与星场视觉，不复制电影镜头、模型、纹理或商标。
- 放下的项目进入黑洞历史，但数据不删除，也不使用失败惩罚文案。
- Canvas 外保留同步的标题、状态、列表和按钮，让键盘与读屏用户可以完成等价操作。

### R4：原创分轨音乐

- 参考歌曲只用于描述用户偏好的能量、空间感、推进和释放，不复制旋律、和弦录音、歌词、采样或解密受保护音频。
- 音乐必须由 TryRevive 自有代码与明确许可的本地资产生成；每项资产记录来源和许可。
- 编曲至少区分氛围、和声、脉冲、旋律、低频、打击与完成冲击层，并用项目历程决定进入、累积、突破、完成和余韵的比例。
- 同一项目数据生成同一首曲目；心情和行动时长变化应产生可听见但仍连贯的变化。
- 代码测试只能证明确定性、格式和边界；“好听、有成就感、与心路历程匹配”必须由产品负责人试听验收。

## 非技术验收

### 手动仪式

1. 打开一个已经完成并选择心情的项目。
2. 不开启摄像头，仅用鼠标依次开封套、拖出唱片、放到唱盘、落针、播放和收藏。
3. 刷新后重复一次，改用键盘；在触屏设备再用触摸重复一次。

算通过：每一步都有清楚的当前状态和唯一主要动作；错误位置松手可以重试；落针前不播放；收藏或离开会停止播放；刷新不丢项目和奖励。

### 降级与辅助功能

1. 拒绝摄像头权限后完成全部仪式。
2. 模拟 WebGL 创建失败或 context lost 后完成全部仪式。
3. 开启减少动画后完成全部仪式。

算通过：三种情况都没有黑屏或死路，主要按钮可由 `Tab` 聚焦，阶段变化由可见文字和 `aria-live` 同步表达。

### 真人手势

在相同光线与机位下，对开封套、捏取、放盘、落针分别尝试 10 次。

进入首轮用户测试的最低门槛：每个动作至少成功 8 次；单个动作误触其他阶段不超过 1 次；失败后不刷新页面即可重试。fake-camera E2E 不能替代这项真人验收。

### 音乐

至少用三个真实但不敏感的已完成项目，分别选择“平静”“踏实的骄傲”“还有能量”试听。

记录四项主观评分：开头是否像回顾、是否有持续推进、完成瞬间是否有释放、结尾是否愿意收藏。任何一项在三首中有两首低于 3/5，就不替换现有默认音乐，并继续调整原创编曲。

## 不在本轮隐含完成的事情

- 不因安装 Three.js 就声称黑胶星球已经通过视觉验收。
- 不因 MediaPipe 返回关键点就声称真人手势准确。
- 不因 WAV 可导出就声称音乐已经好听。
- 不接入、解密、重新分发或提交用户提供的 MP3/NCM 参考歌曲。
- 不启用云端模型、支付、部署或生产域名。
