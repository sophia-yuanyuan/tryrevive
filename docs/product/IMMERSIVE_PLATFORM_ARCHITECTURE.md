# TryRevive 沉浸式桌面平台架构

状态：`CURRENT`（本地沉浸链路）+ `PARTIAL CURRENT`（收费云端链路）。不能据此声称收费云服务已经上线。

基线：`codex/frontend-platform`，更新日期 2026-08-08

## 当前实现状态

`CURRENT`：本地状态已经使用版本 6。Web 使用 IndexedDB，桌面端使用带有效 `.bak` 的原子 JSON 存档；未来版本、损坏或不可理解的数据不会被重建成空白项目。主备份都无法验证时进入恢复锁，只允许导入有效备份，普通写入被阻止。桌面端默认全屏并有可见退出入口；唱针入口需要保持 0.8 秒才开始专注，减少动画时仍保留上下文确认。项目完成或放弃后可进入本地黑胶星球，按真实行动时长和最终心情生成、播放及导出 WAV。

`PARTIAL CURRENT`：Windows 专注守护由用户主动开启，只读取前台进程名和系统空闲时长，具有会话白名单、12 秒宽限、全屏拉回、必要工作临时放行和退出入口。摄像头默认关闭；用户单独同意后，随应用打包的 MediaPipe WASM 可在本机识别旋转、选择和打开手势，且一次保持只触发一次。完成奖励已有 Three.js 真 3D 手动仪式和 WebGL 失败降级，但真人 21 点“捏取、跟随、放盘、落针”尚未接入，也未完成跨浏览器标签页的最小行动判断。

`PARTIAL CURRENT`：桌面端已有安全隔离的云端桥接、加密会话、算力兑换/匿名报价界面、上传前确认和结构化草稿校验。打包版只允许 `https://api.tryrevive.online`，开发环境才允许 localhost。D1 账户、哈希会话、兑换码、匿名报价、幂等预留、结算、失败释放、过期释放和审计账本已经进入仓库，并由真实 SQLite 迁移与纵向测试覆盖。

`PARTIAL CURRENT`：桌面内容客户端已经执行匿名报价、服务端预留、携带预留凭据上传、结算或失败释放的两段式协议；恢复草稿仍要经过 Confirm/Correct 才进入本地项目。Worker 的真实处理方默认硬关闭，且必须同时存在服务端 Secret、审核过的模型和显式批准开关。示例配置没有真实数据库 ID，因此还不能验收真实语音转写或附件理解。

`PARTIAL CURRENT`：Stripe Checkout、webhook 原始请求体验签、重复事件去重、订单级恰好一次入账，以及隐私页面、云端导出、原文不落库核验和账户永久删除都已实现并通过本地自动测试。live 商户配置、真实 OpenAI 凭据、正式身份找回、远端成本熔断、可验证保留期限、法律政策事实和生产域名验证仍未接通。

## 产品决定

TryRevive 不要求普通用户填写任何模型供应商的 API Key。用户购买的是 TryRevive 提供的云端理解能力，而不是学习如何配置第三方开发者服务。

首发采用两层产品边界：

1. 本地层：项目收纳、手工恢复现场、下一步、专注、证据、回流、黑胶收藏和本地生成音乐，不因没有账户或余额而锁住。
2. 云端层：云端语音转写、附件理解、停滞原因分析和自动建议需要账户及预付算力额度。

首次启动不要求注册。用户只有在主动点击云端能力时，才进入账户、价格、上传范围和额度确认流程。

## 用户看到的计费单位

用户不看 token、模型名或供应商账单。界面只显示两个稳定单位：

- 语音理解分钟：按待上传音频的预计分钟数扣除。
- 项目理解次：一次确认过的上下文分析与下一步建议。

首发推荐预付算力包，而不是月底追账。购买后先得到额度，每次调用前显示预计消耗；取消不扣费，服务失败自动归还，成功才结算。

具体人民币价格只有在以下数据被真实测量后才能决定：平均音频时长、附件大小、模型输入输出量、失败率、支付手续费、退款和客服成本。不得直接用上游 API 单价当零售价。

## 云端纵向链路

以下协议已经在客户端与 Worker 中实现，但不是当前已经可用的生产能力：

```text
用户主动选择语音/附件
  -> 本机显示上传范围、预计额度和删除策略
  -> 用户确认
  -> TryRevive 服务端验证账户与余额
  -> 原子预留额度并写入幂等请求号
  -> 服务端以自己的密钥调用转写/分析供应商
  -> 返回结构化草稿与不确定项
  -> 成功结算；失败释放预留额度
  -> 用户确认或修改后才写入本地项目
```

上游密钥只允许存在于云端 Secret。安装包、浏览器存储、日志、错误提示和导出备份中都不得出现密钥。

每位用户仍必须在上传前看到处理方、用途、额度和保留说明并主动确认；产品负责人的开发授权不能替代真实用户的逐次同意。处理完成后 TryRevive 不保存原文，Responses 请求使用 `store: false`；正式上线前还必须确认上游安全日志的适用期限与 TryRevive 的法律说明。域名白名单、余额或接口代码都不能替代这些条件。

## 服务端责任

### 账户与额度

- 账户拥有不可猜测的内部 ID；客户端只持有短期访问令牌和可撤销刷新凭据。
- 余额、预留、结算和退款使用服务端权威账本，不能相信客户端上报余额。
- 每个付费操作必须带幂等请求号，重复请求不能重复扣费。
- 支付成功只能由服务端验证过的支付回调入账，不能相信客户端的“支付成功”页面。
- 每个账户与设备都有速率和每日金额上限；异常时停止云端调用但不破坏本地数据。

### 语音和附件

- 客户端先在本地计算文件类型、大小和音频时长，再展示预计消耗。
- 文本、Markdown、CSV、JSON 优先本地提取；默认只上传用户确认的文本片段。
- PDF、DOCX 和音频在上传前显示文件名、大小、用途和保留期限。
- 临时原文件默认在处理完成或超时后删除；分析结果是否保留由用户决定。
- 单次上传、单次文本量和处理时间都必须设置硬上限。

### 项目分析

服务端返回可验证的结构，而不是一段不可控长文：

- 原始目标；
- 已完成事实；
- 停滞位置与可能原因；
- 截止节点；
- 建议的继续、缩小、求助、暂停或放弃；
- 5–20 分钟下一步及完成标准；
- 不确定项和需要用户确认的内容。

模型结果永远是草稿。用户确认前不能覆盖项目事实、替用户宣布项目完成或自动开始收费的下一次调用。

## 桌面权限责任

麦克风、摄像头和前台窗口监测分别授权，不能用一个总开关捆绑同意。

- 麦克风：只在可见的录音状态中工作，停止后立即释放。
- 摄像头：只在手势界面工作，持续显示预览或摄像头状态，关闭界面立即停止视频轨道。
- 前台窗口：只在用户主动开始的专注时段读取进程名和系统空闲时长；当前版本不读取窗口标题、网页或按键内容。
- 黑幕：偏离白名单并经过宽限期后才显示；始终提供 `Esc`、结束本次专注和“这是必要工作”出口。
- 所有传感器和监测默认关闭，重启应用后不应在用户不知情时自动恢复。

## 黑胶星球和音乐

- 三维黑胶星球使用本地项目状态渲染，不需要把收藏上传云端。
- 手势只是鼠标、触摸和键盘之外的可选入口，不能成为唯一操作方式。
- 黑洞保存已放弃项目的历史入口，不删除数据，也不把放弃描述为失败。
- 音乐由本地项目种子、行动时长和用户自愿选择的心情生成，可在本机导出 WAV。
- 播放、下载和摄像头手势都必须由用户主动触发，并支持减少动态效果。
- 当前 CSS 透视星球与单声道规则合成器属于 `PARTIAL CURRENT`。真 WebGL 仪式、21 点捏取/放盘、黑洞空间和原创分轨音乐必须分别通过 `VINYL_RITUAL_3D_ACCEPTANCE.md`，不能用画布存在、关键点返回或 WAV 可导出代替真人视觉、手势和试听验收。
- 用户提供的歌曲只用于描述偏好，不得解密、采样、提交或重新分发；新音乐只使用 TryRevive 自有代码和许可可核验的本地资产。

## 可见验收

收费云端链路只有同时满足以下条件才算完成：

1. 安装包中没有 API Key 输入框，也没有上游模型配置项。
2. 未登录用户能完成完整本地链路；点击云端理解时能清楚看到为什么需要账户和额度。
3. 上传前能看到文件或录音、预计额度、用途和删除方式，并可取消。
4. 余额不足时不上传；支付或兑换后余额由服务端返回，不由本地伪造。
5. 同一请求重复发送只扣一次；服务失败后预留额度被归还。
6. 云端结果明确标注“待你确认”，修改或拒绝不会损坏原项目。
7. 退出账户、撤回权限或断网后，本地项目仍可打开和导出。

## 上线阻断条件

当前 `worker/` 和桌面客户端已经形成可测试的账户、报价、预留、上传、结算、退款、支付回调和隐私数据控制协议，但真实处理方、支付商户和域名控制面仍未配置；它不是已经上线的可收费服务。正式上线前必须完成并独立验证：

- 删除临时诊断端点；
- 可撤销的正式账户认证与找回流程；
- 在真实 Stripe 商户中配置 Price、live Secret 和 webhook，并用真实测试订单验证验签、重复回调、失败和对账；
- 为生产 Worker 配置真实 OpenAI Secret、经记录审核的模型和显式生产开关；
- `PARTIAL CURRENT`：Worker 已有账号/会话固定分钟桶、账号/全局 UTC 日分析与语音分钟硬限额，并在上游失败退款后保留当天供应商调用计数；上线仍需 Cloudflare 边缘抗滥用、OpenAI/Cloudflare 预算告警与值班停用流程；
- 产品负责人确认真实处理方、具体保留期限和删除方式，随后再启用对应适配器；
- 补全运营主体、司法辖区、可收信隐私邮箱、退款责任人、结果过期策略和真实保留策略；
- 配置根域、`www`、`api`、`staging-api` 和域名所有权 TXT，并让生产预检通过；
- 在受保护的 staging 环境运行真实语音、PDF、DOCX、余额不足、重复请求和上游失败 E2E。

在这些条件完成前，界面只能标记为“云端能力内测/未接通”，不能收取真实款项，也不能声称任意附件都能被完整理解。
