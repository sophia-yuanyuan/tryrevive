# Windows 离线语音入口验收

状态：`CURRENT`（Windows x64 桌面版；真人中文准确率仍需人工验收）

目标：不用用户填写 API Key，也不用启用 TryRevive 云端，把一段本人说明变成待确认的恢复草稿。

## 用户路径

1. 打开 TryRevive Windows 桌面版，在“本地文字材料或你记得的内容”旁点击“用 Windows 本机语音说”。
2. 首次使用时由本人同意麦克风权限；拒绝后不录音，文字、PDF 和 DOCX 入口仍可用。
3. 说出最初目标、上次做到哪里、当前卡在哪里；最长 90 秒。
4. 点击“停止并本机理解”。页面必须明确显示正在离线转写，不能显示上传或算力扣费。
5. 转写成功后直接进入统一的“我猜你做到这里”；确认前没有正式项目，用户仍只能点“正确”或“修改”。

## 隐私与失败边界

- 使用构建时校验 SHA-256、随 Windows 安装包分发的 `whisper.cpp 1.9.1` 与多语种 `base-q5_1` 模型；运行时不下载模型。
- 录音由渲染进程编码为 16 kHz、16-bit、单声道 PCM WAV；主进程只接受不超过 4 MiB、最长 90 秒且包含可听信号的该格式。
- 主进程只在系统临时目录创建随机子目录；转写成功、无声、CLI 错误或超时后都删除 WAV 和派生 TXT。
- 原始录音不写入 TryRevive 存档，离线转写不发送给 TryRevive 后端、OpenAI 或浏览器语音服务。
- 没有录到清晰声音、模型缺失、麦克风拒绝或 180 秒超时，都回到可编辑文字入口，不创建空项目。
- 离线转写是文字线索，不等于完整理解、事实核验、完成判定或成果质量验证。

## 自动验证与人工门

- 自动测试：WAV 编码/边界、权限拒绝、运行时缺失、统一 pending draft、固定模型 SHA、CLI 实际载入模型、Electron IPC 与安装包资源一致。
- 人工测试：安静房间与普通宿舍环境各说 5 段真实中文项目说明；每段核对目标、已完成、卡点三项。十段中至少八段不需要重说，只需在确认页做少量修改，才能把语音入口记为体验通过。
- 自动绿色不能证明真人中文识别质量；未完成上述人工门时只能写“功能可用，准确率待验收”。
