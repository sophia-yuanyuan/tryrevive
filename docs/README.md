# 文档目录

- `product/`：学生 MVP PRD、体验规格、指标与实验，以及 V3 技术候选说明。
- `research/`：真实学生验证计划和研究证据台账。
- `growth/`：90 天 1,000 名估算独立激活学生计划与四平台 Build in Public 手册。
- `decisions/`：供应商解耦、证据门控学习等架构与产品边界决策。
- `deployment/`：部署前检查与运行环境说明。
- `features/`：公众号知识库等独立功能说明。

## 文档职责

- [`product/PRD_STUDENT_MVP.md`](product/PRD_STUDENT_MVP.md) 是当前产品范围和优先级的唯一主 PRD。
- [`product/STUDENT_MVP_EXPERIENCE_SPEC.md`](product/STUDENT_MVP_EXPERIENCE_SPEC.md) 只定义用户逐步看到和选择什么。
- [`product/METRICS_AND_EXPERIMENTS.md`](product/METRICS_AND_EXPERIMENTS.md) 只维护指标公式、事件和实验门槛。
- [`research/RESEARCH_LOG.md`](research/RESEARCH_LOG.md) 是画像、用户故事和效果结论的证据来源。
- [`growth/90_DAY_1000_STUDENTS.md`](growth/90_DAY_1000_STUDENTS.md) 维护增长漏斗和资源分配。
- [`growth/BUILD_IN_PUBLIC_PLAYBOOK.md`](growth/BUILD_IN_PUBLIC_PLAYBOOK.md) 维护平台执行方式，不重复 ICP 和产品需求。
- [`decisions/ADR-002_EVIDENCE_GATED_LEARNING_LOOP.md`](decisions/ADR-002_EVIDENCE_GATED_LEARNING_LOOP.md) 是产品学习权限与回滚的唯一政策源。
- [`product/PRD_V3_REVIVAL_CORE.md`](product/PRD_V3_REVIVAL_CORE.md) 只作为本地 V3 技术实现规格，不决定学生产品优先级。

本地报名稿和其他不准备公开的材料不放在这里，而是保存在已被 Git 忽略的 `private/` 目录。
