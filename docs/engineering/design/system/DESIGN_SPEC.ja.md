# Cohere · Design system migration spec

> Source: https://cohere.com  ·  Curated by OpenDesign  ·  ja

> このサイトは、タイポグラフィと余白を活用して力強さと信頼を伝える、抑制的かつインパクトの強いSaaSデザインの優れた例です。

## 1. デザイン DNA

Cohereのデザインシステムは、厳重に守られた金庫のように機能します。その強みは華やかな装飾ではなく、規律ある構造にあります。アイデンティティは、黒と白の厳格なハイコントラスト基盤から鍛え上げられ、即座に権威とエンタープライズグレードのセキュリティ感を確立します。この目的の明確さが、すべてのコンポーネントとインタラクションを構築する礎となり、移りゆく流行ではなく、強力なAIインフラストラクチャへの焦点を示しています。

**One-liner:** 開発者ツールとデータオーナーシップに特化した、クリーンで高品質なAIプラットフォーム。
**Keywords:** AI · Infrastructure · Ownership · Data · Developer
**Analogy:** 企業向けAIのための、クリーンで高品質なテクノロジープラットフォーム。

## 2. カラー

パレットは抑制の研究であり、ハイコントラストの黒と白の基盤の上に構築されています。アクセントカラーは外科的な精度で使用され、準備完了チップなどの重要なステータスインジケーターにのみ留められ、視覚フィールドを無駄のないものに保ち、プライマリコンテンツに注目が集まるようにしています。

| Token | 値 | 用途 |
|---|---|---|
| `--bg` | `#FFFFFF` | main background |
| `--bg-soft` | `#F9FAFB` | card background |
| `--ink` | `#000000` | body text |
| `--ink-soft` | `#4B5563` | secondary text |
| `--muted` | `#9CA3AF` | placeholder |
| `--accent` | `#1E1E1E` | single accent |
| `--line` | `rgba(229, 231, 235, 1.0)` | divider |

**カラー原則:** 高コントラストのモノクロームに、階層構造のために控えめなグレーを用い、イラストにはブランド固有のカラーでアクセントを加える。

原則は絶対的です。コントラストと明確さを何より優先し、特定の機能的意味を持つ場合にのみカラーを使用します。

## 3. タイポグラフィ

タイポグラフィはクリーンなジオメトリック・サンセリフで設定され、モダンかつ権威あるトーンを確立します。スケールは意図的に限定され、主に威圧的なヒーローヘッドラインと、段落やナビゲーションのための正確で読みやすいテキストを区別し、装飾的な華やかさよりも情報の階層を強化しています。

- **Display:** sans-serif
- **Body:** sans-serif
- **Mono:** monospace

| Token | Size | Line-height | Weight | Letter-spacing | 用途 |
|---|---|---|---|---|---|
| display | 56px | 1.1 | 400 | -1px | プライマリヘッドライン（Own your AI） |
| headline | 32px | 1.2 | 400 | 0px | サブヘッドライン（Your data...） |
| body | 16px | 1.5 | 400 | 0px | 標準本文テキスト |
| caption | 14px | 1.4 | 400 | 0px | 二次情報 |

**タイポルール:**
- ディスプレイフォントは非常に読みやすいサンセリフ体。
- 本文テキストは標準のシステムフォントスタックをフォールバックとして使用。
- コード要素には等幅フォントを使用。

## 4. 余白

豊かな垂直方向のスペースがシステムのリズムを定義し、レイアウト内で各要素が自由に呼吸できるようにします。

- **Base unit:** 4px
- **Scale:** 4 / 8 / 16 / 24 / 32 / 48 / 64 / 96 px
- **Rhythm:** 豊かな余白と標準の8ptベースのspacing scale。

## 5. サーフェス (角丸 / 影 / 罫線)

深度は、寸法効果ではなく、クリーンな分離によって伝達されます。表面は、微細な1pxボーダーよりも、むしろホワイトスペースとレイアウト配置のインテリジェントな使用に依存し、境界を定義しています。

- **Radius:** sm 4px · md 8px · lg 12px · pill 999px
- **Shadows:**
  - 0px 4px 6px -1px rgba(0, 0, 0, 0.1)
- **Borders:** 1px solid #E5E7EB

## 6. レイアウト

レイアウトのスケルトンは、中心に配置された単一カラムのヒーローから始まり、権威を持ってコアメッセージを確立します。その後、製品やユースケースを明確かつ視覚的に豊かに展示するために設計された、マルチカラムのビジュアルグリッドに移行します。

- **Container max:** 1200px
- **Paragraph max:** 680px
- **Grid:** 12 columns, gutter 24px
- **Breakpoints:** 768 / 1024 px

**Skeleton:** 中央揃えコンテナを持つ標準の12カラムグリッド。

## 7. モーションとインタラクション

モーションの哲学は、専門的な目的と最小限の介入に基づいています。デュレーションは、一貫したイージングカーブに支配され、集中を散らすことを避けながら、微細（220ms）から中程度（800ms）まで較正され、明確でスムーズなステート変化を実現します。

- **Durations:** micro 220ms · small 400ms · medium 800ms
- **Easing:** `cubic-bezier(0.4, 0, 0.2, 1)`
- **Patterns:**
  - hover状態のスムーズなトランジション。
  - コンテンツセクションの控えめなフェードイン。

- **Hover:** 控えめな色の変化または微小な浮き上がり。
- **Click:** スケールダウンまたは色の変化。
- **Transition:** すべてのプロパティがスムーズにトランジション（all 0.2s ease）。
- **Keyboard:** アクセシビリティのための標準的なfocusアウトライン。

## 8. 文体と禁止事項

エディトリアルボイスは、権威があり、自信に満ち、直接的です。見出しは短く断定的なステートメントであり、行動を促す呼びかけは明確でアクション指向であり、デザインそのものの率直な精度を反映しています。

- **Tone:** プロフェッショナルで、自信に満ち、ややテクニカルなトーン。
- **Headline style:** 直接的で、力強く、ベネフィット重視。
- **CTA style:** アクション重視（例：デモをリクエスト、製品を探索）。
- **Avoid:** ジャーニーの過剰使用 / 不必要なカジュアルなトーン / 曖昧なフレージング

### 禁止事項
- ❌ ドロップシャドウを使用しない — スクリーンショットでは控えめなボーダーを使用したフラットデザインが示されている
- ❌ 複雑なグラデーションを使用しない — スクリーンショットではクリーンな白い背景が示されている
- ❌ 装飾的なアイコンを使用しない — スクリーンショットでは最小限のアイコン使用が示されている
- ❌ 本文テキストに全角大文字を使用しない — スクリーンショットでは標準の文頭大文字が示されている
- ❌ 鮮やかなプライマリカラーを背景に使用しない — スクリーンショットでは白地に暗いテキストが示されている
- ❌ ヘッドラインにセリフフォントを使用しない — スクリーンショットではクリーンなサンセリフ体が示されている

システムは、そのシリアスでエンタープライズ志向の姿勢を維持するために、遊び心のある言葉、複雑なグラデーション、装飾的な要素を意図的に省いています。
